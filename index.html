核心特性

简洁而完整

编译到字节码

源码经编译器生成紧凑的 .aeo 字节码文件，魔数 AeBc，大端编码，结构清晰。

栈式虚拟机

基于操作数栈执行，采用类型化标签值模型（Tagged Value），运行时跟踪 int / double / string / bool。

自动类型提升

int 与 double 混合运算时自动提升为浮点，比较运算支持整型与浮点两种指令集，无需手动转换。

控制流完整

支持 if/else、while 循环，以及 break 和 continue（含嵌套循环回填），编译期占位 + 链接期重写。

反汇编工具

内置 aed 反汇编器，可将 .aeo 字节码反汇编为可读的汇编格式伪代码，方便调试与分析。

复合赋值

支持 += -= *= /= 复合赋值运算符，结合全局变量槽位管理，编写更简洁。

工具链

三个工具，完整的编译-执行链路

01

aec 编译器

词法分析 → 递归下降语法分析 → 代码生成 → 链接

.ae → .aeo
02

ae 虚拟机

字节码加载 → 常量池解析 → 指令调度执行

.aeo → 运行
03

aed 反汇编器

解析文件头 + 常量池 → 逐条反汇编指令流

.aeo → 汇编

快速开始

三步运行你的第一段 Ae 代码

1

编写源码

// hello.ae
main {
    pr("你好，世界")

    double x = 10
    double y = 3.14
    pr(x * y)

    if (true) {
        pr("自动类型提升 ✓")
    }
}
2

编译为字节码

$ aec main.ae
✓ 编译成功: main.ae → main.aeo
  (常量池 4 项, 代码 28 字节)
3

运行程序

$ ae main.aeo
